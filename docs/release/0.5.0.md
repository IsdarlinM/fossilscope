# FossilScope 0.5.0 Release Candidate

## Public 0.5 surfaces

CLI:

```text
fossilscope reobservation-priority CANDIDATES.json [--max-requests N]
```

Local API:

```text
POST /api/v1/analysis/reobservation/prioritize
```

The planner schedules passive evidence refresh and never proves present exposure. It does not send network requests. Active HTTPS re-observation remains a separate scope/approval-gated workflow.

Direct JSON import now uses the bounded regular-file loader, including symlink and size checks.

## Release validation

Use the coordinated Sentinel Forge 0.5 release train from sibling checkouts. `doctor` requires SRIC 0.5 for this candidate.
