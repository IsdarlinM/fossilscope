# FossilScope 0.5.13

Date: 2026-08-10

## Guided Web Security Console

FossilScope keeps its passive-first temporal dashboard while moving complete operations to the SRIC Core 0.5.13 guided Security Console.

- Dashboard navigation is `Dashboard / Security Console / API`.
- `All Features` and `Advanced Console` are removed from the user-facing navigation.
- The Security Console uses operation cards, checkboxes, selectors, numeric/path controls and structured repeated-value controls instead of command/argv entry.
- `/console` remains only as a compatibility alias to `/workbench` and no longer exposes a command composer.
- Timeline, fossil candidates, lifecycle, graph and explainability views remain domain-native.
- Historical evidence remains explicitly separate from current exposure; candidate scores do not become vulnerability severity.

## Runtime and supply chain

- Product version: 0.5.13.
- SRIC Core floor: `>=0.5.13,<0.6`.
- First-party runtime pin: GitHub-verified SRIC commit `bd90fe668e4a2a23c00a39f7d63df1c092b63c12`.
- Bootstrap transition chain includes `0.5.12 -> 0.5.13` plus same-version 0.5.13 repair.
- Linux and Windows installers require SRIC 0.5.13, retain atomic product/SRIC installation, `pip check`, Web-runtime import probes and quiet doctor/help smokes.
